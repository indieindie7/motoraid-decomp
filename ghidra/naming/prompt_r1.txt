Arcade game Motor Raid (Sega AM1, 1997) on the Sega Model 2A board: main CPU Intel i960 KB (little-endian, 32-bit), program ROM at 0x0-0xfffff. Research only. Game: futuristic bike combat racer (riders attack each other with weapons while racing; course select, rider select, ranking, attract demo, service/test menus, backup settings). Code at 0x200000-0x23ffff is the fast-RAM copy of ROM 0xb0000-0xcffff (hot routines: maths, geometry, display list), made at boot.
Hardware (from the public MAME model2 driver): 0x800000 geo / 0x804000 TGP FIFO (geometry coprocessor: matrices, polygons and lights are sent as command words), 0x880000 copro, 0x900000 bufferram, 0x980000 video control, 0xe00000 CPU control, 0xe80000 IRQ request/enable, 0xf00000 timers, 0x1000000 tilemap (text/2D layers), 0x1800000 palette, 0x1810000 colour translation, 0x181c000 z-clip, 0x1a00000 comm board (linked cabinets), 0x1c00000 I/O (steering, throttle, brake, buttons, coins, lamps, sound commands), 0x1c80000 UART, 0x1d00000 backup SRAM, 0x2000000+ data ROM, 0x10000000+ render mode / polygon count. Work RAM is 0x500000-0x5fffff.
Names already given (stub_/retN_) are trusted. Some blocks carry a "/* decider hint: ... */" line: hw= hardware blocks touched (tags as above: geo, tgp_fifo, copro, bufferram, videoctl, cpuctl, irq, timer, ramctl, tile, palette, colorxlat, zclip, comm, io, uart, backup, main_data, render), float=N count of float/double uses, str= strings (Ghidra string labels with _ turned into spaces). Use them. Debug strings like "NF/NR/FF/FR x:y:z", "Spd", "MySpd", "MyPnt"/"TgPnt" mark bike physics and AI debug printers.
